# Dependencies for Windows. requirements.txt is a Linux freeze: its triton, nvidia-* and cuda-* pins
# have no Windows wheels, and one unsatisfiable pin makes `pip install -r` install nothing. They are
# left out here (the Windows PyTorch wheels carry their own CUDA runtime).
#
#   .venv\Scripts\python.exe -m pip install -r requirements-windows.txt
#
# PyPI's Windows torch / torchvision are CPU-only. For a GPU, install them first from the PyTorch
# index that matches your driver (the selector at https://pytorch.org/get-started/locally), e.g.
#   .venv\Scripts\python.exe -m pip install torch==2.12.0 torchvision==0.27.0 --index-url https://download.pytorch.org/whl/<cuXXX>
# then run the command above; pip keeps the installed builds because the versions already match.
#
# Not covered: the camera. modules/vision opens a V4L2 device (/dev/videoN), so the real camera
# pipeline does not run on Windows; the console, the PLC links, simulate_feeder, the PLC simulator,
# the sandbox and the tests do not need it.
